# server — `@devdigest/api`

Fastify 5 API: imports repos/PRs, indexes with `repo-intel`, stores agents, runs reviews via `reviewer-core`. Port 3001.

## Stack
Node ≥ 22 · TypeScript (`strict`, `noUncheckedIndexedAccess`) · Fastify 5 + `fastify-type-provider-zod` · Drizzle ORM + `postgres` · Postgres 16 + pgvector (Docker) · Zod · Vitest (+ testcontainers) · **pnpm**.

## Map
- `src/modules/<feature>/` — self-contained Fastify plugin: `routes.ts` → `service.ts` → `repository.ts` (+ `constants.ts`, `index.ts`).
- `src/adapters/` — ports (llm, github, git, astgrep, secrets…) behind the DI container `src/platform/container.ts`; test doubles in `src/adapters/mocks.ts`.
- `src/db/schema/*.ts` — Drizzle schema. It already has tables for future milestones; empty tables are expected.
- `src/vendor/shared` — `@devdigest/shared` Zod contracts (also route schemas). `repo-intel` lives in `src/modules/repo-intel`.

## Commands
```sh
pnpm dev                 # API :3001 (tsx watch)
pnpm db:migrate          # NOT run on boot — run after pulling or generating migrations
pnpm db:seed             # idempotent demo data
pnpm db:generate         # after editing src/db/schema/*.ts
pnpm typecheck
pnpm exec vitest run --exclude '**/*.it.test.ts'   # unit, hermetic
pnpm exec vitest run .it.test                      # integration, needs Docker
```
Before finishing: typecheck + unit; integration when you touched DB/routes.

## Conventions
- Files `kebab-case.ts`; module files use the fixed names above. Don't add business logic to `routes.ts`.
- Tests live in `test/`. Anything importing `test/helpers/pg.ts` (real Postgres) **must** be named `*.it.test.ts` — the unit lane excludes that glob.
- Tests are hermetic: use `MockLLMProvider` / `MockGitClient`; no real keys or network.
- Define request/response shapes as Zod contracts in `@devdigest/shared`, not ad-hoc types.
- Secrets are read only through `LocalSecretsProvider` (`src/adapters/secrets/local.ts`); never log or persist keys in DB/git.

## Do not touch
- `src/db/migrations/**` (incl. `meta/` snapshots): generated by drizzle-kit. Never hand-edit or renumber. Change schema → `pnpm db:generate` → new migration. Migration `0000` enables pgvector.
- `pnpm-lock.yaml`: only via `pnpm add/remove`. Don't mix in npm/yarn.
- `clones/` (runtime git clones), `dist/`, `node_modules/`, `.env`.
